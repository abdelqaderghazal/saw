# استبيان وزارة الشؤون الاجتماعية والعمل

<div dir="rtl">

نظام استبيان إلكتروني مبني على **Google Apps Script** و**Google Sheets** لجمع وتحليل بيانات قياس الرأي العام حول وزارة الشؤون الاجتماعية والعمل في الجمهورية العربية السورية.

![الجمهورية العربية السورية](https://img.shields.io/badge/الجمهورية%20العربية%20السورية-الوزارة-green)
![Google Apps Script](https://img.shields.io/badge/Google%20Apps%20Script-Enabled-blue)
![Google Sheets](https://img.shields.io/badge/Google%20Sheets-Data%20Storage-green)

---

## 📋 محتويات المشروع

| الملف | الوصف |
|-------|-------|
| `Code.gs` | الكود الخلفي (Backend) - منطق حفظ البيانات وتحليلها |
| `Index.html` | الواجهة الأمامية (Frontend) - نموذج الاستبيان |
| `appsscript.json` | إعدادات مشروع Google Apps Script |

---

## ⚡ المميزات

- ✅ **واجهة عربية احترافية** بتصميم متجاوب (Responsive)
- ✅ **تخزين تلقائي** في Google Sheets
- ✅ **نظام تحليلات** مدمج لاستخراج إحصائيات الاستبيان
- ✅ **تقييم بنجوم** (Star Rating) تفاعلي
- ✅ **تنقل متعدد المراحل** (6 مراحل)
- ✅ **تحقق من صحة البيانات** قبل الإرسال
- ✅ **دعم خيار "أخرى"** مع نص حر
- ✅ **معرف فريد** (UUID) لكل استجابة

---

## 🚀 طريقة التثبيت

### 1. إنشاء مشروع Google Apps Script

1. افتح [Google Apps Script](https://script.google.com)
2. أنشئ مشروع جديد
3. احذف الملف `Code.gs` الافتراضي

### 2. رفع الملفات

1. أنشئ ملف جديد باسم `Code.gs` والصق محتوى `Code.gs`
2. أنشئ ملف جديد باسم `Index.html` والصق محتوى `Index.html`
3. أنشئ ملف `appsscript.json` (اختياري - للإعدادات المتقدمة)

### 3. إعداد Google Sheets

1. أنشئ جدول بيانات Google Sheets جديد
2. اربطه بالمشروع عبر **محرر النصوص ← الخدمات ← Google Sheets API**
3. شغّل الدالة `setupSurvey()` مرة واحدة لإنشاء ورقة `SurveyData`

### 4. نشر التطبيق

1. اذهب إلى **نشر ← نشر جديد**
2. اختر **تطبيق ويب**
3. اضبط الوصول على **أي شخص، حتى المجهولين**
4. انقر **نشر** وانسخ الرابط

## 📊 هيكل البيانات

يتم حفظ البيانات في ورقة `SurveyData` بالأعمدة التالية:

| العمود | الوصف |
|--------|-------|
| `start` | وقت بدء تعبئة الاستبيان |
| `end` | وقت إرسال الاستبيان |
| `الجنس` | ذكر / أنثى |
| `العمر` | العمر بالسنوات |
| `المستوى التعليمي` | أمي / ابتدائي / ثانوي / جامعي ... |
| `الوضع الوظيفي` | موظف / عامل / طالب ... |
| `مصادر المعلومات` | الإعلام / التواصل الاجتماعي / الجمعيات ... |
| `مهام الوزارة` | توفير عمل / رعاية الفئات الهشة / مساعدات ... |
| `الحماية والرعاية` | نعم بشكل كبير / إلى حد ما / ضعيفة ... |
| `فرص العمل` | ممتازة / جيدة / متوسطة ... |
| `تقييم الخدمات` | 1 إلى 5 نجوم |
| `التواصل` | نعم / إلى حد ما / لا ... |
| `الأولويات` | توفير عمل / رعاية اجتماعية / تدريب ... |
| `الاقتراحات` | نص حر |
| `_uuid` | معرف فريد للاستجابة |
| `_index` | رقم الصف |

## 🔧 التحليلات

الدالة `getSurveyAnalytics()` تُرجع JSON يحتوي على:

- `total` : عدد الاستجابات
- `gender` : توزيع الجنس
- `age` : توزيع الفئات العمرية
- `education` : توزيع المستويات التعليمية
- `employment` : توزيع الوظائف
- `informationSources` : مصادر المعلومات
- `tasks` : مهام الوزارة المختارة
- `protection` : تقييم الحماية
- `jobs` : تقييم فرص العمل
- `services` : متوسط تقييم الخدمات + التوزيع
- `communication` : تقييم التواصل
- `priorities` : الأولويات المختارة
- `suggestions` : آخر 20 اقتراح
- `lastUpdate` : وقت آخر تحديث

## 🛠️ التطوير باستخدام Clasp

يمكنك استخدام [clasp](https://github.com/google/clasp) لإدارة المشروع من سطر الأوامر:

```bash
# تثبيت clasp
npm install -g @google/clasp

# تسجيل الدخول
clasp login

# استنساخ المشروع
clasp clone <SCRIPT_ID>

# رفع التغييرات
clasp push

# نشر التطبيق
clasp deploy
```
